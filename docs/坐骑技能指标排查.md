## 固伤口径

固伤倍率为 `总固伤 / X`，固伤修正为 `总固伤 / X / CD`。每个技能等级单独反推 X；现有有效样本的角色等级均为 `5 × (技能等级 - 1)`，没有发现跨角色等级混用。采样排除纯治疗/增益卡、每段均为 0/1 的占位固伤；相同技能和数值在多个形态中只投票一次，关闭配置不参与反推。哮天犬仍可使用该 X 展示比值。

凶恶风暴修正后的固伤预算约 18.5714X，修正约 92.86%；原来的约 114.29% 来自共享命中重复计数。黄龙治疗不再参与伤害基准。其他固伤随等级变化时保留逐等级明细，不用中位数覆盖成长曲线。

以下高值有配置依据，予以保留：

- 多种无双为 30X、CD 21 秒，固伤修正约 142.86%；梼杌无双 CD 20.5 秒，对应约 146.34%。这些不是攻转或固伤公式错误。
- 年兽咬击为 550% 纯攻击伤害、43 帧，攻转约 3.837；固伤的 1 是占位，不补造固伤。
- 地狱马冥狱之怒有三处独立冥火，各 470%，全中上限 1410%、56 帧、攻转约 7.554。目标体积与站位决定能否全中，卡片已说明全中口径。原表低等级固伤曲线较高，Lv.1 修正约 300%，Lv.26 起约 100%；这是原表成长差异，不修改官方伤害值。
